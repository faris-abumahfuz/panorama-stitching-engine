# Classical Panorama Stitching Engine

A modular image processing pipeline built from scratch in Python and NumPy that aligns, warps, and seamlessly blends overlapping photographs into wide-angle panoramas without using `cv_2.Stitcher`.

## Quick Start
```bash
..\venv\Scripts\Activate.ps1
python main.py --input_dir data/raw --output data/output/panorama.jpg --blend multiband
```
